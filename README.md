# Liuyang Jinye Farm Field Imagery Dataset

## Overview

This repository contains multi-temporal field images collected at Jinye Farm in Liuyang, Hunan Province, China, during 2025 and 2026. The images are organized by acquisition date. Two acquisition dates also include separate folders labeled **斜拍** (oblique-view photography).

本仓库收录湖南省浏阳市金叶农场于 2025—2026 年采集的田间影像，按拍摄日期整理。其中两个拍摄日期包含单独的“斜拍”影像文件夹。

## Dataset Information

- **Collection location:** Jinye Farm, Liuyang, Hunan, China.
- **Collection period:** April 2025 to May 2026.
- **Organization:** Six folders representing four collection dates, including two additional oblique-view image groups.
